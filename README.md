# Rigged Wheel – Issue Tracker

Welcome! 👋

This repository is the public home for bug reports, feature ideas, and general feedback for **Rigged Wheel**.

Rigged Wheel includes collaborative tools such as a customizable wheel, planning poker, and a snail race. The source code itself is kept private, but feedback and suggestions are very welcome here.

## How you can help

### Report a bug

Please open an issue and include:

- What you were trying to do
- What happened instead
- What you expected to happen
- Steps to reproduce the problem, if possible
- Your device, browser, or operating system
- Screenshots or recordings, if they help explain the issue

### Suggest a feature

Have an idea that would make the app more useful or more fun? Open an issue and tell me:

- What problem the feature would solve
- How you imagine it working
- Who it would be useful for

Small ideas are welcome too!

## Before opening an issue

Please take a quick look through the existing issues first. If someone has already reported the same bug or suggested the same feature, feel free to add a comment or reaction instead.

## Pull requests

The source repository is private, so pull requests are not accepted through this repository. If you would like to help implement something, open an issue first and describe what you would like to contribute.
